# Jankyard-Wars

運用ルール:
- このリポジトリの公開バージョンは `VERSION` ファイルで管理します。
- 修正をコミットする際は `VERSION` の値に 0.01 を加算してコミットしてください（例: 0.01 -> 0.02）。
- タイトル画面は `VERSION` を読み込んで表示します（読み込みに失敗した場合はフォールバック値を使用します）。

ローカルでの実行方法（簡易）:
1. リポジトリをクローン
2. ディレクトリへ移動: `cd Jankyard-Wars`
3. ローカルで簡易HTTPサーバを起動（例: `python -m http.server 8000`）
4. ブラウザで `http://localhost:8000/` を開く
